Lockdown

Digital security monitoring for connected accounts

Lockdown is a consumer digital-security application designed to help users monitor connected email accounts for suspicious mailbox behaviour, forwarding or filtering changes, and security-related messages that may indicate account compromise.

Yahoo Mail integration

Lockdown is requesting read-only Yahoo Mail access through OAuth 2.0 and IMAP so users can opt in to mailbox-security monitoring. The intended use is to detect suspicious mailbox behaviour and relevant security metadata, then alert the user for review.

Lockdown does not use Yahoo Mail access to send email, delete messages, modify mailbox settings, advertise to users, build advertising profiles, or sell mailbox data.

Security and data handling

  • Access is user-authorised.
  • Mailbox access is intended to be read-only.
  • Authentication credentials and tokens are stored encrypted on the backend.
  • Mailbox data is used only to provide the security-monitoring features requested by the user.
  • Lockdown does not sell user data or use mailbox data for advertising or profiling.
